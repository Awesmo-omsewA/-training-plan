# 📖 Глоссарий

---

| Термин | Что значит |
|--------|------------|
| **HSPU** | Отжимания в стойке на руках (Handstand Push-Up) |
| **Front lever** | Передний вис — тело горизонтально полу на турнике |
| **Back lever** | Задний вис — тело горизонтально полу лицом вниз |
| **Hollow body hold** | Полый вис — лёжа на спине, поясница прижата, руки и ноги на весу |
| **L-sit** | Уголок — удержание тела на прямых руках, ноги параллельны полу |
| **L-sit raises** | Подъёмы ног из L-sit вверх и обратно |
| **Dead bug** | «Мёртвый жук» — лёжа на спине, опускаешь противоположные руку и ногу |
| **Bird-dog** | «Птица-собака» — на четвереньках, вытягиваешь противоположные руку и ногу |
| **Pallof press** | Жим Палофа — анти-ротационное упражнение с резинкой |
| **Posterior pelvic tilt** | Задний наклон таза — подкручивание таза назад |
| **Anterior pelvic tilt** | Передний наклон таза — прогиб в пояснице |
| **Anti-extension** | Анти-разгибание — способность не давать пояснице прогнуться |
| **Anti-rotation** | Анти-ротация — способность не давать корпусу повернуться |
| **Tuck** | Группировка — колени прижаты к груди |
| **Advanced tuck** | Продвинутая группировка — колени разогнуты, голени параллельны полу |
| **Straddle** | Разведённые ноги |
| **One-leg** | Одна нога прямая, вторая согнута |
| **Full** | Полная версия упражнения |
| **Scapular pulls** | Тяга лопатками — в висе сводишь лопатки без сгибания рук |
| **МФР** | Миофасциальный релиз — прокатка роликом или мячом |
| **Hip flexors** | Сгибатели бедра — подвздошно-поясничная, прямая мышца бедра |
| **Buttwink** | Подкручивание таза назад в нижней точке приседа |
| **Deficit** | Дефицит — выполнение с увеличенной амплитудой (руки на возвышении) |
